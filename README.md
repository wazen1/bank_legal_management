# نظام إدارة الشؤون القانونية (Bank Legal Management)

تطبيق مستقل على منصة Frappe/ERPNext لإدارة شؤون المصحف القانونية باللغة العربية، مع
صلاحيات دقيقة، وسير عمل قابل للتدقيق، وإدارة شكاوى الموظفين عبر مسارين:
**إدارة الشؤون القانونية** و**لجنة شكاوى الموظفين**.

> التطبيق مُثبَّت على الموقع `lib.ly` باسم `bank_legal_management` (الإصدار 1.0.0).

## الوحدات (Modules)

| الوحدة | النطاق | المحتوى |
|---|---|---|
| إدارة القضايا القانونية | القضايا والجلسات | قضية، جلسة، مستشار، أطراف، مطالبات، تكليفات، قضايا مرتبطة |
| إدارة العقود القانونية | العقود والالتزامات | عقد، التزام تعاقدي، سجل اعتمادات |
| الآراء القانونية | الطلبات والآراء | طلب رأي، نسخة رأي |
| شكاوى الموظفين | الشكاوى وسجل الإجراءات | شكوى موظف، توضيح، سجل إجراءات |
| إدارة اللجان | لجان شكاوى الموظفين | لجنة، اجتماع، بنود، حضور |
| المراسلات القانونية | المراسلات | مراسلة واردة/صادرة/داخلية |
| المستندات القانونية | سجل المستندات | سجل مستند + نسخ المستند |
| المصروفات القانونية | المصروفات | مصروف قانوني (أتعاب، رسوم، ترجمة، سفر) |
| التقارير القانونية | التقارير | خمسة تقارير تشغيلية + بطاقات ومخططات |
| إدارة الشؤون القانونية | الإعدادات والتنبيهات | إعدادات، سجل تنبيهات، مستلمو التنبيه |

## التثبيت

```bash
bench --site lib.ly install-app bank_legal_management
bench --site lib.ly migrate
bench build --app bank_legal_management
```

بعد التثبيت تُنشأ تلقائيًا: الأدوار، الـ Workflows الثلاثة، بطاقات ومخططات لوحة
المعلومات، مساحة العمل **نظام إدارة الشؤون القانونية**، وإعدادات افتراضية.

## البنية السريعة

```
bank_legal_management/
├── hooks.py                 # الصلاحيات، الـ scheduler، doc_events، أصول الواجهة
├── setup.py                 # الأدوار، الـ Workflows، البطاقات، إعدادات Space
├── permissions.py           # نطاقات الصلاحيات على مستوى السجل والقوائم
├── file_guard.py            # إجبار المرفقات الحساسة على الخصوصية ومنع نقلها
├── tasks.py                 # process_legal_deadlines (تنبيهات الجلسات/العقود/الآراء)
├── api.py                   # واجهات REST للعمليات المسموح بها فقط
├── utils.py                 # مساعدات مشتركة (الأدوار، الموظفون، الإشعارات)
├── legal_case_management/   # القضايا والجلسات
├── legal_contract_management/# العقود والالتزامات
├── legal_opinions/          # طلبات الرأي ونسخ الرأي
├── employee_grievances/     # شكاوى الموظفين وسجل الإجراءات
├── committee_management/    # اللجان والاجتماعات
├── legal_correspondence/     # المراسلات
├── legal_documents/         # سجل المستندات
├── legal_expenses/          # المصروفات
├── legal_reporting/         # التقارير الخمسة
├── legal_management/        # الإعدادات، القرارات، سجل التنبيهات، مساحة العمل
└── tests/                   # 63 اختبارًا آليًا
```
