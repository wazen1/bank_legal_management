# الأدوار والصلاحيات وسير العمل

## 1. الأدوار

| الدور | الصلاحية الأساسية |
|---|---|
| `Legal System Administrator` | صلاحية كاملة على كل سجلات النظام القانوني (إنشاء/تعديل/اعتماد/إلغاء/حذف) |
| `Legal Department Manager` | إدارة القضايا: اعتماد العقود والآراء، إغلاق القضايا، اعتماد المصروفات والقرارات |
| `Legal Officer` | موظف قانوني: إنشاء القضايا والعقود والآراء والمراسلات |
| `Legal Case Manager` | إدارة القضايا والجلسات |
| `Legal Contract Officer` | إدارة العقود والالتزامات |
| `Legal Opinion Officer` | إعداد الآراء القانونية ونسخها |
| `Legal Document Officer` | سجل المستندات والمراسلات |
| `Legal Expense Officer` | تسجيل المصروفات وإرسالها للمراجعة |
| `Legal Auditor` | قراءة وتصدير فقط دون تعديل (تدقيق) |
| `Legal Opinion Requester` | تقديم طلبات الرأي ومتابعة طلبه |
| `Employee Grievance Submitter` | الموظف: إنشاء شكوى له وتقديمها ومتابعتها |
| `Legal Grievance Officer` | معالجة شكاوى مسار الشؤون القانونية |
| `Legal Grievance Manager` | معالجة شكاوى مسار الشؤون القانونية + التحويل بين المسارات |
| `Employee Complaints Committee Chair` | إدارة اللجنة واجتماعاتها واعتماد المحاضر |
| `Employee Complaints Committee Secretary` | إدارة اجتماعات اللجنة |
| `Employee Complaints Committee Member` | الاطلاع على شكاوى اللجنة |
| `Authorized Decision Maker` | إصدار قرارات الشكاوى واعتماد الآراء والقرارات |

## 2. نطاق الصلاحيات على الشكاوى

| المستخدم | ما يراه | ما يفعل |
|---|---|---|
| صاحب الشكوى | شكاواه فقط | إنشاء، تعديل المسودة، تقديم، الرد على طلب المعلومات |
| مسؤول الشكاوى القانونية | الشكاوى المقدمة على مسار الشؤون القانونية | قبول، طلب معلومات، توصية، إحالة للقرار، إغلاق |
| رئيس/أمين اللجنة | الشكاوى المقدمة على مسار اللجنة | قبول، توصية، جدولة، إحالة، إغلاق |
| المعتمد المخوّل | الشكاوى في حالة «بانتظار القرار» و«صدر القرار» | إصدار القرار |
| المدقق القانوني | كل الشكاوى | قراءة وتصدير فقط |
| مدير النظام القانوني | كل الشكاوى | كل العمليات |

التنفيذ في `permissions.py` عبر:

- `permission_query_conditions`: تقييد القوائم (List View) حسب المسار والمالك.
- `has_permission`: تقييد العمليات على مستوى السجل (تعديل/تقديم/حذف/تصدير).

## 3. نطاق الصلاحيات على السجلات المرتبطة

`Legal Correspondence` و`Legal Document Register` و`Legal Expense` و`Legal Opinion Request`
و`Legal Opinion` و`Grievance Action Log` تتبع نطاق الشكوى المرتبطة (`related_grievance`)
عند وجودها، وتُقيَّد كذلك حسب دور المستخدم.

## 4. سير العمل (Workflows)

| DocType | حالات الـ Workflow | ملاحظات |
|---|---|---|
| `Legal Case` | Draft → Registered → Under Review → Assigned → In Progress → Hearing Scheduled / Awaiting Documents / Awaiting Judgment → Judgment Issued → Under Appeal / Settled → Closed → Archived | الأرشفة لمدير النظام القانوني فقط |
| `Legal Contract` | Draft → Under Legal Review → Returned for Amendment / Pending Approval → Pending Signature → Active → Expiring / Terminated / Expired / Renewed → Archived | `allow_self_approval = 1` لكل الانتقالات |
| `Legal Opinion Request` | Draft → Submitted → Under Review → Awaiting Clarification / Draft Opinion → Legal Review → Pending Approval → Approved / Rejected → Closed | الاعتماد متاح للمعتمد المخوّل فقط |

`Employee Legal Grievance` يستخدم **آلة حالات مخصّصة** داخل الـ Controller (وليس Workflow)
لأن Frappe يسمح بـ Workflow نشط واحد فقط لكل DocType، ولأن الشكوى تحتاج فروعًا
(مساران) وسجل إجراءات.

## 5. قواعد المنع والرقابة

1. `Grievance Action Log`: يُنشأ من الخادم فقط، غير قابل للتعديل أو الحذف.
2. `Employee Legal Grievance`: بعد التقديم تُمنع التعديلات المباشرة على الحقول المحكومة.
3. `Legal Decision`: بعد الاعتماد لا يعدَّل، والتعديل التصحيحي يتطلب مدير النظام القانوني.
4. `Employee Complaints Committee Meeting`: المحضر يُعتمد من رئيس اللجنة ولا يعتمده من أعدّه.
5. `Legal Expense`: الاعتماد لمدير الشؤون القانونية، والرفض يتطلب سببًا.
6. `Employee Complaints Committee`: لا يمكن حذف لجنة مرتبطة بشكاوى أو اجتماعات.
7. المرفقات على السجلات القانونية إلزامية الخصوصية (`is_private = 1`) ولا يمكن نقلها.
8. **فصل المُعِدّ عن المعتمد**: معدّ التوصية لا يوصي القرار بنفسه (قابل للتفعيل/تعطيل من الإعدادات).
